# Business English — контекст для AI-разработчика

Тренажёр бизнес-английского: пользователь добавляет слова с урока, AI генерирует рабочие фразы на русском, пользователь переводит, AI проверяет. Роли: автор проекта — PM, код пишет Claude. Язык интерфейса и документации — русский.

## Источники правды
- Требования: PRD v0.1 в вики проекта (`01 Product/PRD — MVP`), user stories US-1…US-5.
- Макеты: прототип «Business English — экраны v0.1» (9 экранов телефона).
- Задачи: трекер Notion, номер задачи `ET-N`. Архитектура и схема БД: вики `04 Tech/Стек и архитектура`.
- Вики и трекер лежат вне репозитория; если нужной информации нет в задаче — спросить PM, не додумывать требования.

## Архитектурные правила
- Вся логика на сервере (Server Components, Server Actions, Route Handlers); клиентские компоненты — только для интерактивности.
- Каждый Server Action, Route Handler и серверная страница с данными начинается с `await requireSession()` из `src/lib/auth.ts`. `src/proxy.ts` — лишь предварительный фильтр.
- База — только через `getSupabase()` из `src/lib/supabase.ts` (секретный ключ, `server-only`). Никаких `NEXT_PUBLIC_`-переменных с ключами.
- Изменения схемы — новым файлом в `supabase/migrations/` (имя `YYYYMMDDHHMMSS_описание.sql`), с `enable row level security` и `grant … to service_role` для новых таблиц. Выполненные миграции не редактировать. Схему в вики обновляет задача, которая её меняет.
- Секреты — только в переменных окружения; `.env.example` обновлять при добавлении переменной.
- LLM (когда будет выбран провайдер): фразы на сессию — одним запросом, проверка ответа — отдельным коротким запросом (PRD, раздел 5).

## Интерфейс
- Мобильный first: ширина от 375px, контент в колонке до 480px.
- Токены из прототипа заданы в `src/app/globals.css`: фон `paper` #F5F2EA, текст `ink` #1C1E22, вторичный `muted` #5B5F67, линии `line` / `line-strong`, акцент `accent` #2A47A3, предупреждение `warn-bg` / `warn-ink`.
- Шрифты: Literata (`font-serif`) — заголовки и фразы; Golos Text (`font-sans`) — интерфейс. Подключены локально через Fontsource.
- Кнопки 52px, радиус 12px; кликабельные элементы не меньше 44px; настоящие `<button>`, `<a>`, `<label>`.

## Процесс
- Одна задача — одна ветка `et-N-кратко` и один pull request в `main`. PM сливает PR после приёмки.
- Перед push: `npm run lint` и `npm run build` без ошибок.
- Сообщения коммитов — на русском, в повелительном наклонении, с номером задачи: `ET-14: добавить вход по PIN-коду`.
